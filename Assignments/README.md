## Coverage

These assignments comprehensively cover the following topics:

- **Graphics Primitives**: Line drawing (DDA, Bresenham's), circle and ellipse algorithms
- **Transformations**: 2D/3D translation, rotation, scaling, reflection, shearing
- **Viewing & Clipping**: Window-to-viewport mapping, Cohen-Sutherland clipping
- **Curves**: Bezier curves, B-spline curves, parametric representations
- **Rendering**: Hidden surface removal, illumination models, shading techniques
